This repository holds generated, published web content in `gh-pages/`:

* A phonetic version of MAM (*Miqra al pi ha-Masora*): `index.html`, `tnkh/` (Sefardic), and `tnkh-ashkenaz/` (Ashkenazic)
* Phonetic test-suite pages: `testsuites.html` and `testsuite-*.html`
* Excerpts from my adaptation of Israel Yeivin's *Introduction to the Tiberian Masorah* (ITM), translated and edited by E. J. Revell: `yeivin_itm*.html` (adapted by permission; see the copyright notice on those pages)

Apart from `py/tests`, this repository contains no code. The content of `gh-pages/` is generated by code in the private [MAM-private](https://github.com/bdenckla/MAM-private) repository, in its `al-hatorah/` tree, so changes belong in the generators there, not in hand-edits here. That tree was the repository [al-hatorah](https://github.com/bdenckla/al-hatorah) until 2026-08-10; `bdenckla/al-hatorah` stays alive, holding a breadcrumb README and its issue tracker.

The issue tracker of this repository is the home for issues about the phonetic version of MAM.

One more related tree exists: `masorah-books/`, also in MAM-private, which holds sources and tooling related to the ITM adaptation. Among other things, `masorah-books/` tracks which sections of the adaptation are faithful renderings and which are liberally adapted. The `masorah-books/` tree is kept private for copyright reasons. It was the repository [masorah-books](https://github.com/bdenckla/masorah-books) — named yeivin-itm until 2026-07-31 — until 2026-08-10, and that repository too stays alive for its issue tracker.
