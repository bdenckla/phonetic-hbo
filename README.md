This repository holds generated, published web content in `gh-pages/`:

* A phonetic version of MAM (*Miqra al pi ha-Masora*): `index.html`, `tnkh/` (Sefardic), and `tnkh-ashkenaz/` (Ashkenazic)
* Phonetic test-suite pages: `testsuites.html` and `testsuite-*.html`
* Excerpts from my adaptation of Israel Yeivin's *Introduction to the Tiberian Masorah* (ITM), translated and edited by E. J. Revell: `yeivin_itm*.html` (adapted by permission; see the copyright notice on those pages)

Apart from `py/tests`, this repository contains no code. The content of `gh-pages/` is generated by code in the private [al-hatorah](https://github.com/bdenckla/al-hatorah) repository, so changes belong in the generators there, not in hand-edits here.

The issue tracker of this repository is the home for issues about the phonetic version of MAM.

One more related repository exists: masorah-books (named yeivin-itm until 2026-07-31), which holds sources and tooling related to the ITM adaptation. It is kept private for copyright reasons. Among other things, it tracks which sections of the adaptation are faithful renderings and which are liberally adapted.
